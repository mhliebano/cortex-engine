SDK Híbrido de Alto Rendimiento para aplicaciones de escritorio 2D/3D. Capa de UI declarativa orientada a objetos en Pure Dart respaldada por un motor gráfico nativo GPU en Rust (Raylib C-ABI).

Pure Dart Frontend Rust GPU FFI Zero-GC Allocation CSS Style System Desktop MDI Shell 2,234 Material Icons

1. Visión General y Arquitectura

Cortex Engine es un framework desacoplado diseñado para construir software de escritorio (CAD, herramientas de ingeniería, aplicaciones administrativas y simuladores) combinando la velocidad de ejecución nativa en GPU de Rust con la expresividad declarativa de Dart.

Gestión de Memoria FFI
Rendimiento
Optimización Zero-Allocation a nivel FFI reutilizando punteros nativos Pointer<Utf8> para mantener 60+ FPS estables sin pausas de Recolección de Basura (GC).
Estilos Declarativos
CSS System
Registro centralizado de hojas de estilo globales mediante Style.register('nombre', Style(...)) y aplicación desacoplada por propiedad className.
Disposición Automática
Layout Engine
Disposición responsiva con contenedores Column, Row y Panel sin cálculo manual de coordenadas absolutas (X, Y).

3. Herramienta CLI (`cortex`)

Comandos del binario ejecutable cortex disponible en el PATH del sistema:

Comando Sintaxis Descripción

run cortex run Ejecuta la aplicación en modo desarrollo compilando JIT el archivo bin/main.dart.

4. Sistema de Estilos Globales (`Style`)

La clase Style administra las propiedades visuales. Permite registrar clases CSS en bin/app_styles.dart y aplicarlas en los componentes con className: "nombre-clase".

Propiedad Tipo Descripción
bgColorColorRGBA?Color de fondo principal.
hoverColorColorRGBA?Color de fondo en estado Hover (puntero encima).
textColorColorRGBA?Color del texto.
borderColorColorRGBA?Color del borde exterior.
accentColorColorRGBA?Color de acento primario (utilizado en selecciones y elementos activos).
activeColorColorRGBA?Color en estado presionado.
dividerColorColorRGBA?Color de líneas de división.
fontSizeint?Tamaño de tipografía vectorial en píxeles.
paddingint?Margen interno de relleno en píxeles.
spacingint?Espaciado entre elementos hijos.
width / heightint?Dimensiones explícitas del elemento.
borderRadiusdouble?Radio de redondeo de esquinas.
bin/app_styles.dart 
import 'package:cortex/cortex.dart';

void initAppStyles() {
  // Estilo del Panel Principal
  Style.register('main-panel', const Style(
    bgColor: ColorRGBA(24, 28, 36),
    padding: 24,
  ));

  // Estilo de Ítems de Lista
  Style.register('list-item', const Style(
    padding: 12,
    borderRadius: 8,
    bgColor: ColorRGBA(32, 40, 52),
    hoverColor: ColorRGBA(48, 60, 78),
  ));
}

5. Vistas, Reactividad & El Método `rebuild()`

Las pantallas heredan de la clase base View. Cuando el estado interno de tu aplicación cambia (por ejemplo, al recibir una respuesta de red, modificar un listado o filtrar datos), debes invocar rebuild() para forzar la reconstrucción declarativa de la interfaz.

💡 Reactividad en View: El método rebuild() invalida los elementos visuales actuales y ejecuta la función build() nuevamente aplicando el nuevo estado de los datos.
Método Lifecycle Descripción
onInit()Se invoca al instanciar la vista. Ideal para peticiones asíncronas o carga de estado inicial.
build()Construye y retorna la jerarquía declarativa de widgets (List<Element>).
rebuild()Fuerza la reconstrucción reactiva de la vista llamando a build().
onUpdate(dt, input)Hook invocado en cada cuadro (frame) para actualizar lógica de estado o eventos de ratón/teclado.
onResize(width, height)Se ejecuta automáticamente al redimensionar la ventana de la aplicación.

6. Sistema de Navegación (`Navigator`)

El motor de navegación desacoplado de Cortex administra la tabla de rutas de la aplicación con soporte para carga diferida (Lazy Loading) e integración automática con entornos de escritorio MDI.

Navigator API
Navigator.registerRoutes(Map<String, ViewBuilder> routes) | Navigator.to(String route, {bool fullscreen = false})

Permite cambiar de pantalla en la zona central body de un DesktopLayout sin recargar menús ni barras laterales, o navegar a pantallas completas cuando fullscreen: true.

Método / Propiedad Sintaxis Descripción
registerRoutes Navigator.registerRoutes({'home': () => HomeView()}) Registra el mapa central de rutas de la aplicación con constructores de vistas diferidos.
initialRoute Navigator.initialRoute = 'home' Establece la ruta inicial por defecto cargada al arrancar la app.
to Navigator.to('detalles', fullscreen: false) Navega a la ruta especificada. Si fullscreen es false, sustituye únicamente el cuerpo central (body).
pushNamed / push Navigator.pushNamed('editor') Alias intuitivos equivalentes a Navigator.to(...).
Ejemplo de Configuración de Rutas y Navegación 
// Registrar la tabla de rutas
Navigator.registerRoutes({
  'dashboard': () => DashboardView(),
  'config': () => SettingsView(),
  'editor3d': () => Editor3DView(),
});

// Cambiar de pantalla reactivamente desde un botón o ítem
Button(
  label: "Abrir Ajustes",
  icon: Icons.settings,
  onPressed: () => Navigator.to('config'),
);

7. Layouts & Maquetación: `Column` y `Row`

Contenedores flexibles de disposición vertical (Column) y horizontal (Row). Calculan automáticamente las coordenadas sin necesidad de posicionamiento manual (X, Y).

Column & Row
Column({List<Element> children, int? spacing, int? padding, bool isScrollable = false, MainAxisAlignment mainAxisAlignment, CrossAxisAlignment crossAxisAlignment, MainAxisSize mainAxisSize, Expand? expand})

Disponen los elementos en una secuencia lineal. Si isScrollable: true, habilitan desplazamiento fluido por rueda de ratón y barra de scroll arrastrable.

Parámetro Tipo Predeterminado Descripción
childrenList<Element>RequeridoLista de elementos visuales contenidos.
spacingint?10Espacio en píxeles entre cada hijo contiguo.
paddingint?0Margen interno de relleno.
isScrollableboolfalseHabilita barra de desplazamiento interactiva si el contenido desborda.
mainAxisAlignmentMainAxisAlignmentstartAlineación en el eje principal (start, center, end, spaceBetween, spaceAround, spaceEvenly).
crossAxisAlignmentCrossAxisAlignmentstretchAlineación en el eje secundario (start, center, end, stretch).
mainAxisSizeMainAxisSizemaxDimensión del eje principal (max o min).
Ejemplo de Layout Flexible con Column y Row 
Column(
  expand: Expand.all,
  spacing: 16,
  padding: 20,
  children: [
    Row(
      spacing: 12,
      mainAxisAlignment: MainAxisAlignment.spaceBetween,
      children: [
        Label("Filtros de Búsqueda", fontSize: 18),
        Button(label: "Actualizar", icon: Icons.refresh, onPressed: _refresh),
      ],
    ),
    Column(
      isScrollable: true,
      spacing: 8,
      children: _buildContentList(),
    ),
  ],
)

8. Contenedores Visuales: `Panel` y `Expand`

El componente Panel encapsula un contenido dentro de una caja de visualización estructurada (fondos, bordes, sombras y redondeo) y gestiona la propiedad de expansión flexible mediante el enum Expand.

Panel
Panel({String? className, int width = 0, int height = 0, int? padding, Element? child, bool clipContent = false, Expand? expand, bool fillWidth = false, bool fillHeight = false})

Card visual que aplica colores de fondo, bordes, márgenes y recorta los hijos desbordados cuando clipContent: true.

Parámetro / Enum Tipo Descripción
childElement?Widget único contenido dentro del Panel.
paddingint?Margen interno de relleno.
clipContentboolRecorta el renderizado visual al límite del panel.
Expand.allExpandExpande el elemento en ancho y alto (100% W x 100% H del contenedor padre).
Expand.heightExpandExpande el elemento para tomar la máxima altura disponible.
Expand.widthExpandExpande el elemento para tomar el máximo ancho disponible.
Expand.noneExpandMantiene el tamaño explícito dado en píxeles.
Ejemplo de Panel con Estilos CSS y Expansión 
Panel(
  className: "main-panel",
  expand: Expand.all,
  clipContent: true,
  child: Column(
    spacing: 12,
    children: [
      Label("Panel de Propiedades"),
      TextField(placeholder: "Buscar parámetro..."),
    ],
  ),
);

9. Entorno de Escritorio MDI (`DesktopLayout`)

Estructura base MDI para aplicaciones de ingeniería y administración. Organiza automáticamente barras de menú superiores, barras de herramientas, barras laterales de navegación y zonas centrales de trabajo.

DesktopLayout
DesktopLayout({MenuBar? menuBar, ToolBar? toolBar, SideBar? sideBar, StatusBar? statusBar, Element? body, Expand expand = Expand.all})

Contenedor raíz que calcula dinámicamente las regiones y permite intercambiar el body central mediante DesktopLayout.activeLayout?.body = miNuevaVista.

Región / Propiedad Tipo Descripción
menuBarMenuBar?Barra superior de menús desplegables (MenuItem, SubMenu).
toolBarToolBar?Barra horizontal con botones rápidos de acción o herramientas.
sideBarSideBar?Panel lateral de navegación con categorías o árbol de archivos.
statusBarStatusBar?Barra inferior de estado (muestra mensajes, progreso o estado de la red).
bodyElement?Área de contenido central asignada a las vistas del Navigator.

LoadingIndicator & Divider
LoadingIndicator({int size = 36, ColorRGBA? color}) | Divider({int height = 16, int thickness = 1})

Ejemplo de Renderizado Dinámico con LoadingIndicator y ListItem

_cargando

          return ListItem(

      );

17. Renderizado Tridimensional (`Viewport3D`)

Componente de integración GPU para visualizar espacios tridimensionales (geometrías, cámaras en órbita, mallas 3D y simulaciones) acelerado nativamente en Rust mediante Raylib C-ABI.

Viewport3D
Viewport3D({int width = 0, int height = 0, ColorRGBA objectColor = ColorRGBA.accentBlue, Expand? expand})

Renderiza una cuadrícula 3D y mallas volumétricas dentro del lienzo 2D de la interfaz con control interactivo de cámara.

18. Estructura de Proyecto Estandarizada

Punto de entrada oficial utilizando el paquete de la distribución package:cortex/cortex.dart:

bin/main.dart 
import 'package:cortex/cortex.dart';
import 'app_styles.dart';

void main() async {
  // 1. Inicializar registro de estilos globales
  initAppStyles();

  // 2. Configurar la aplicación de escritorio
  final app = Application(
    title: 'Cortex Engine Application',
    width: 1024,
    height: 720,
  );

  // 3. Registrar tabla de rutas
  Navigator.registerRoutes({
    'home': () => HomeView(),
  });

  Navigator.initialRoute = 'home';

  // 4. Ejecutar el ciclo de renderizado GPU
  await app.run();
}
